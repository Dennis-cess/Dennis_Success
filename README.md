###What I'm Building
🧠 Niro — Nigerian Research Optimizer

A privacy-first, local-first econometrics workbench for African social scientists.

Zero user data transiting the network after file upload
Pyodide WASM running Python econometrics entirely in the browser
IndexedDB via Dexie.js for local storage
Multi-agent AI architecture (Gemini, Qwen, Gemma 2b)
Built for researchers who can't afford expensive statistical software

"Niro exists because African researchers deserve tools built for their reality, not tools built for Silicon Valley and ported over as an afterthought."

🤖 AI Economic Research Chatbot

A multi-agent n8n workflow that pulls live data from IMF, World Bank, and OpenAlex APIs to answer economic research questions with cited, structured outputs.

Google Gemini + OpenRouter model integration
MongoDB Chat Memory for persistent sessions
Google Docs integration for context loading
Built and running in production on Docker
📊 Market Research Intelligence Bot

An automated n8n pipeline tracking AI and economics news across tech and development economics intersections — pulling from OpenAlex, World Bank, and NewsData.io APIs.
